## Ideia Geral
O projeto visa automatizar o controle financeiro de uma república estudantil, substituindo planilhas manuais por um sistema onde os moradores podem lançar gastos, visualizar saldos individuais e conferir o histórico da "caixinha".

## Descrição Geral do Sistema
O sistema permitirá:
* Cadastro de moradores e despesas fixas/variáveis.
* Cálculo automático de rateio entre os membros.
* Registro de pagamentos e pendências.
* Geração de relatórios mensais de entradas e saídas.
